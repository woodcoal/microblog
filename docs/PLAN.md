## 技术风险与应对

| 风险                   | 影响             | 应对                                      |
| ---------------------- | ---------------- | ----------------------------------------- |
| Prisma + D1 兼容性问题 | 部署失败         | 开发阶段用本地 SQLite，部署前验证 D1 适配 |
| 热门排序性能           | 大数据量下查询慢 | 缓存排序结果，定时更新                    |
| 文件上传安全           | 恶意文件上传     | 严格类型白名单 + 大小限制 + 文件内容校验  |
| Markdown XSS           | 安全漏洞         | 白名单标签 + 禁用危险协议 + 内容转义      |
| Webhook 失败           | 通知丢失         | 记录发送日志，失败重试（后续增加）        |
