# 第二章：文档管理

文档是 DaLi.Lens 的核心数据单元。你的网站内容（文章、教程、产品说明等）需要先推送给 DaLi.Lens 进行处理，之后才能被推荐和检索。

---

## 2.1 核心概念

### 文档生命周期

```
推送文档 → pending（排队中）→ processing（处理中）→ completed（完成，可被推荐/检索）
                                              ↘ failed（处理失败）
```

### ExternalId 机制

每个文档需要一个 `externalId`——这是**你定义的**文档标识，而非系统生成的 ID。这样你可以用自己系统中的文章 ID、SKU 编号等作为 `externalId`，无需维护两套 ID 映射。

> `externalId` 在同一渠道内必须唯一。

---

## 2.2 文档入库

### 接口

```
POST /api/documents
```

### 请求体

```json
{
	"externalId": "article_12345",
	"title": "Kubernetes 集群部署指南",
	"content": "本文详细介绍如何从零开始部署一个 Kubernetes 集群...(完整正文)",
	"category": "云原生"
}
```

| 字段         | 类型   | 必填 | 约束                      | 说明               |
| ------------ | ------ | ---- | ------------------------- | ------------------ |
| `externalId` | string | 是   | 最大 200 字符，渠道内唯一 | 你的业务文档 ID    |
| `title`      | string | 是   | 最大 500 字符             | 文档标题           |
| `content`    | string | 是   | 最大 51200 字节 (50KB)    | 文档全文           |
| `category`   | string | 否   | 最大 100 字符             | 分类标签，用于筛选 |

### 响应

```json
{
	"success": true,
	"data": {
		"id": 1893456789012345678,
		"externalId": "article_12345",
		"status": "pending",
		"createdAt": "2026-06-20T10:30:00Z"
	}
}
```

> `status` 为 `pending` 表示文档已入队，系统正在后台异步处理。

### 前端集成示例

```javascript
/**
 * 推送文档到 DaLi.Lens
 * @param {Object} doc - 文档信息
 * @param {string} doc.externalId - 业务文档 ID
 * @param {string} doc.title - 文档标题
 * @param {string} doc.content - 文档全文
 * @param {string} [doc.category] - 分类标签
 * @returns {Promise<Object>} 入库结果
 */
async function ingestDocument(doc) {
	return await callApi(`${BASE_URL}/api/documents`, {
		method: 'POST',
		body: JSON.stringify(doc)
	});
}

// 使用示例
const result = await ingestDocument({
	externalId: 'article_12345',
	title: 'Kubernetes 集群部署指南',
	content: '完整正文内容...',
	category: '云原生'
});

console.log(`文档已入库，状态: ${result.status}`);
```

### 常见错误

| 场景              | 错误码              | HTTP 状态码 | 处理方式               |
| ----------------- | ------------------- | ----------- | ---------------------- |
| externalId 已存在 | `CONFLICT`          | 409         | 提示用户或使用更新接口 |
| 内容超过 50KB     | `CONTENT_TOO_LARGE` | 413         | 截断内容或分篇入库     |
| 标题或 ID 为空    | `VALIDATION_ERROR`  | 400         | 前端预校验             |

## 2.3 批量入库

一次提交最多 100 篇文档，部分失败不影响其他文档。

### 接口

```
POST /api/documents/batch
```

### 请求体

数组格式，每项结构同单条入库：

```json
[
	{ "externalId": "doc_001", "title": "文档1", "content": "内容1", "category": "分类A" },
	{ "externalId": "doc_002", "title": "文档2", "content": "内容2" },
	{ "externalId": "doc_003", "title": "文档3", "content": "内容3", "category": "分类B" }
]
```

### 响应

```json
{
	"success": true,
	"data": [
		{
			"id": 1893456789012345678,
			"externalId": "doc_001",
			"status": "pending",
			"createdAt": "..."
		},
		{
			"id": 1893456789012345679,
			"externalId": "doc_002",
			"status": "pending",
			"createdAt": "..."
		},
		{ "externalId": "doc_003", "Error": "CONFLICT", "Message": "externalId 'doc_003' 已存在" }
	]
}
```

> 批量入库中，单条失败以 `Error` 字段标记，不影响其他条目。前端应逐条检查结果。

### 前端集成示例

```javascript
/**
 * 批量推送文档
 * @param {Array<Object>} documents - 文档数组（最多 100 条）
 * @returns {Promise<Object>} 批量结果，含成功和失败项
 */
async function batchIngest(documents) {
	if (documents.length > 100) {
		throw new Error('单次批量入库最多 100 条');
	}

	const results = await callApi(`${BASE_URL}/api/documents/batch`, {
		method: 'POST',
		body: JSON.stringify(documents)
	});

	// 分离成功和失败项
	const succeeded = results.filter((r) => !r.Error);
	const failed = results.filter((r) => r.Error);

	return { succeeded, failed };
}
```

## 2.4 查询文档状态

文档入库后，系统异步处理（分块、向量化、摘要生成）。你需要轮询此接口确认处理完成。

### 接口

```
GET /api/documents/{externalId}
```

### 响应

```json
{
	"success": true,
	"data": {
		"id": 1893456789012345678,
		"externalId": "article_12345",
		"title": "Kubernetes 集群部署指南",
		"category": "云原生",
		"status": "completed",
		"summary": "本文介绍 Kubernetes 集群部署的完整流程...",
		"chunkCount": 8,
		"errorMessage": null,
		"createdAt": "2026-06-20T10:30:00Z",
		"updatedAt": "2026-06-20T10:30:15Z"
	}
}
```

### 状态说明

| status       | 含义                        | 是否可推荐/检索 |
| ------------ | --------------------------- | --------------- |
| `pending`    | 已入队，等待处理            | 否              |
| `processing` | 正在处理中                  | 否              |
| `completed`  | 处理完成                    | 是              |
| `failed`     | 处理失败，查看 errorMessage | 否              |

### 前端轮询示例

```javascript
/**
 * 等待文档处理完成
 * @param {string} externalId - 外部文档 ID
 * @param {number} [maxRetries=30] - 最大轮询次数
 * @param {number} [interval=2000] - 轮询间隔（毫秒）
 * @returns {Promise<Object>} 处理完成的文档信息
 */
async function waitForCompletion(externalId, maxRetries = 30, interval = 2000) {
	for (let i = 0; i < maxRetries; i++) {
		const doc = await callApi(`${BASE_URL}/api/documents/${externalId}`);

		if (doc.status === 'completed') return doc;
		if (doc.status === 'failed') {
			throw new Error(`文档处理失败: ${doc.errorMessage}`);
		}

		// pending 或 processing，继续等待
		await new Promise((resolve) => setTimeout(resolve, interval));
	}

	throw new Error('文档处理超时');
}
```

## 2.5 文档列表

### 接口

```
GET /api/documents?page=1&pageSize=20&category=云原生&status=completed
```

### 查询参数

| 参数       | 类型   | 必填 | 说明                                                          |
| ---------- | ------ | ---- | ------------------------------------------------------------- |
| `page`     | int    | 否   | 页码，默认 1                                                  |
| `pageSize` | int    | 否   | 每页条数，默认 20，最大 100                                   |
| `category` | string | 否   | 按分类筛选                                                    |
| `status`   | string | 否   | 按状态筛选：`pending` / `processing` / `completed` / `failed` |

### 响应

```json
{
	"success": true,
	"data": {
		"items": [
			{
				"id": 1893456789012345678,
				"externalId": "article_12345",
				"title": "Kubernetes 集群部署指南",
				"category": "云原生",
				"status": "completed",
				"createdAt": "2026-06-20T10:30:00Z"
			}
		],
		"totalCount": 42,
		"page": 1,
		"pageSize": 20
	}
}
```

### 前端集成示例

```javascript
/**
 * 获取文档列表
 * @param {Object} [filters] - 筛选条件
 * @param {string} [filters.category] - 分类筛选
 * @param {string} [filters.status] - 状态筛选
 * @param {number} [filters.page=1] - 页码
 * @param {number} [filters.pageSize=20] - 每页条数
 */
async function listDocuments(filters = {}) {
	const params = new URLSearchParams();
	if (filters.category) params.set('category', filters.category);
	if (filters.status) params.set('status', filters.status);
	params.set('page', filters.page || 1);
	params.set('pageSize', filters.pageSize || 20);

	return await callApi(`${BASE_URL}/api/documents?${params}`);
}
```

## 2.6 更新文档

更新文档内容时，系统自动删除旧数据并重新处理。

### 接口

```
PUT /api/documents/{externalId}
```

### 请求体

结构同入库接口（`externalId`、`title`、`content`、`category`），全部字段必填。

### 前端集成示例

```javascript
/**
 * 更新文档内容
 * @param {string} externalId - 外部文档 ID
 * @param {Object} updatedDoc - 更新后的完整文档
 */
async function updateDocument(externalId, updatedDoc) {
	return await callApi(`${BASE_URL}/api/documents/${externalId}`, {
		method: 'PUT',
		body: JSON.stringify(updatedDoc)
	});
}
```

> 更新后文档状态会重置为 `pending`，需要等待重新处理完成。

---

## 2.7 删除文档

删除文档及其所有向量数据，删除后该文档不再出现在推荐和检索结果中。

### 接口

```
DELETE /api/documents/{externalId}
```

### 响应

```json
{
	"success": true,
	"data": { "deleted": true }
}
```

### 前端集成示例

```javascript
/**
 * 删除文档
 * @param {string} externalId - 外部文档 ID
 */
async function deleteDocument(externalId) {
	return await callApi(`${BASE_URL}/api/documents/${externalId}`, {
		method: 'DELETE'
	});
}
```

## 2.8 典型场景

### 场景一：CMS 系统发布文章时自动入库

```javascript
// 在 CMS 的文章发布钩子中调用
async function onArticlePublished(article) {
	try {
		await ingestDocument({
			externalId: `cms_${article.id}`,
			title: article.title,
			content: article.body,
			category: article.categoryName
		});
	} catch (err) {
		if (err.code === 'CONFLICT') {
			// 文章已存在，执行更新
			await updateDocument(`cms_${article.id}`, {
				externalId: `cms_${article.id}`,
				title: article.title,
				content: article.body,
				category: article.categoryName
			});
		}
	}
}
```

### 场景二：文章下架时删除

```javascript
async function onArticleUnpublished(article) {
	await deleteDocument(`cms_${article.id}`);
}
```

### 场景三：批量导入历史内容

```javascript
async function importHistoricalArticles(articles) {
	// 每批最多 100 条
	const batchSize = 100;

	for (let i = 0; i < articles.length; i += batchSize) {
		const batch = articles.slice(i, i + batchSize).map((a) => ({
			externalId: `cms_${a.id}`,
			title: a.title,
			content: a.body,
			category: a.categoryName
		}));

		const { succeeded, failed } = await batchIngest(batch);

		console.log(`批次 ${i / batchSize + 1}: 成功 ${succeeded.length}, 失败 ${failed.length}`);
	}
}
```
