# 第三章：用户系统

用户是推荐系统的核心。DaLi.Lens 通过用户的行为反馈构建用户画像，从而提供个性化推荐。

---

## 3.1 核心概念

### UserId 机制

与文档的 `externalId` 类似，用户 ID 也由你定义。你可以使用自己系统中的用户 ID、会员编号等，无需维护映射关系。

> `userId` 在同一渠道内必须唯一，最大 128 字符。

### 用户画像

用户画像是 DaLi.Lens 根据用户行为自动构建的兴趣模型，包含：

- **交互统计**：用户的总反馈次数
- **分类偏好**：用户偏好的内容分类及权重
- **标签偏好**：用户偏好的关键词标签

> 画像由系统自动维护，你只需要通过反馈接口上报用户行为即可。

---

## 3.2 创建用户

当你的系统中出现新用户时，需要通知 DaLi.Lens 创建对应用户。

### 接口

```
POST /api/users
```

### 请求体

```json
{
	"userId": "user_12345",
	"username": "张三",
	"metadata": "{\"department\": \"技术部\", \"level\": \"senior\"}"
}
```

| 字段       | 类型   | 必填 | 说明                                      |
| ---------- | ------ | ---- | ----------------------------------------- |
| `userId`   | string | 是   | 你的业务用户 ID，渠道内唯一               |
| `username` | string | 是   | 用户名，用于后台展示                      |
| `metadata` | string | 否   | 扩展元数据，JSON 格式，可存储任意业务信息 |

### 响应

成功时返回用户信息。若 `userId` 已存在，返回 409 错误。

### 前端集成示例

```javascript
/**
 * 注册用户到 DaLi.Lens
 * @param {Object} user - 用户信息
 * @param {string} user.userId - 业务用户 ID
 * @param {string} user.username - 用户名
 * @param {string} [user.metadata] - 扩展元数据（JSON 字符串）
 */
async function createUser(user) {
	try {
		return await callApi(`${BASE_URL}/api/users`, {
			method: 'POST',
			body: JSON.stringify(user)
		});
	} catch (err) {
		if (err.code === 'CONFLICT') {
			// 用户已存在，忽略即可
			console.log(`用户 ${user.userId} 已存在`);
			return null;
		}
		throw err;
	}
}
```

### 典型场景：用户注册时自动创建

```javascript
// 在你的用户注册流程中调用
async function onUserRegistered(user) {
	await createUser({
		userId: user.id,
		username: user.displayName,
		metadata: JSON.stringify({
			department: user.department,
			level: user.level
		})
	});
}
```

## 3.3 查询用户

### 接口

```
GET /api/users/{userId}
```

### 前端集成示例

```javascript
/**
 * 查询用户信息
 * @param {string} userId - 业务用户 ID
 * @returns {Promise<Object|null>} 用户信息，不存在时返回 null
 */
async function getUser(userId) {
	try {
		return await callApi(`${BASE_URL}/api/users/${userId}`);
	} catch (err) {
		if (err.code === 'NOT_FOUND') return null;
		throw err;
	}
}
```

## 3.4 用户列表

### 接口

```
GET /api/users?searchTerm=张&page=1&pageSize=20
```

| 参数         | 类型   | 必填 | 说明                        |
| ------------ | ------ | ---- | --------------------------- |
| `searchTerm` | string | 否   | 按用户名或 ID 模糊搜索      |
| `page`       | int    | 否   | 页码，默认 1                |
| `pageSize`   | int    | 否   | 每页条数，默认 20，最大 100 |

### 前端集成示例

```javascript
/**
 * 搜索用户
 * @param {string} keyword - 搜索关键词
 * @param {number} [page=1] - 页码
 */
async function searchUsers(keyword, page = 1) {
	const params = new URLSearchParams();
	if (keyword) params.set('searchTerm', keyword);
	params.set('page', page);

	return await callApi(`${BASE_URL}/api/users?${params}`);
}
```

## 3.5 更新用户

### 接口

```
PUT /api/users/{userId}
```

### 请求体

```json
{
	"username": "李四",
	"metadata": "{\"department\": \"产品部\", \"level\": \"manager\"}"
```

| ---------- | ------ | ---- | -------------- |
| `username` | string | 是   | 新用户名       |
| `metadata` | string | 否   | 新的扩展元数据 |

### 前端集成示例

```javascript
/**
 * 更新用户信息
 * @param {string} userId - 业务用户 ID
 * @param {Object} updates - 更新内容
 */
async function updateUser(userId, updates) {
	return await callApi(`${BASE_URL}/api/users/${userId}`, {
		method: 'PUT',
		body: JSON.stringify(updates)
	});
}
```

## 3.7 用户画像

查看用户当前的兴趣画像，了解系统对用户偏好的理解。

### 接口

```
GET /api/users/{userId}/profile
```

### 响应

```json
{
	"success": true,
	"data": {
		"userId": "user_12345",
		"interactionCount": 42,
		"topCategories": [
			{ "category": "云原生", "weight": 0.45 },
			{ "category": "网络配置", "weight": 0.3 },
			{ "category": "安全防护", "weight": 0.15 }
		],
		"lastUpdatedAt": "2026-06-20T18:30:00Z"
	}
}
```

### 字段说明

| 字段               | 说明                                     |
| ------------------ | ---------------------------------------- |
| `interactionCount` | 用户累计反馈次数                         |
| `topCategories`    | 用户偏好的内容分类，按权重降序排列       |
| `weight`           | 偏好权重，0~1 之间，所有分类权重之和为 1 |
| `lastUpdatedAt`    | 画像最后更新时间                         |

### 前端集成示例

```javascript
/**
 * 获取用户画像
 * @param {string} userId - 业务用户 ID
 * @returns {Promise<Object>} 用户画像数据
 */
async function getUserProfile(userId) {
	try {
		return await callApi(`${BASE_URL}/api/users/${userId}/profile`);
	} catch (err) {
		if (err.code === 'NOT_FOUND') {
			// 新用户，尚无画像
			return { userId, interactionCount: 0, topCategories: [] };
		}
		throw err;
	}
}
```

### 典型场景：展示用户兴趣标签

```javascript
async function renderUserInterests(userId) {
	const profile = await getUserProfile(userId);

	if (profile.interactionCount === 0) {
		return '<p>暂无偏好数据，浏览更多内容后将生成个性化推荐</p>';
	}

	const tags = profile.topCategories
		.filter((c) => c.weight > 0.05)
		.map((c) => `<span class="tag">${c.category} (${Math.round(c.weight * 100)}%)</span>`)
		.join('');

	return `<div class="interest-tags">${tags}</div>`;
}
```

## 3.8 兴趣分析

### 接口

```
GET /api/users/{userId}/interests
```

与用户画像类似，但对新用户有更友好的处理——返回空数据而非错误。

### 前端集成示例

```javascript
/**
 * 获取用户兴趣分析（新用户安全）
 * @param {string} userId - 业务用户 ID
 */
async function getUserInterests(userId) {
	return await callApi(`${BASE_URL}/api/users/${userId}/interests`);
}
```

## 3.9 典型场景

### 场景一：用户注册时自动创建 + 首页推荐

```javascript
async function onUserLogin(user) {
	// 确保用户存在于 DaLi.Lens
	const existing = await getUser(user.id);
	if (!existing) {
		await createUser({
			userId: user.id,
			username: user.displayName
		});
	}

	// 获取首页推荐
	const recommendations = await getRecommendations(user.id);
	renderHomePage(recommendations);
}
```

### 场景二：用户资料页展示兴趣画像

```javascript
async function renderProfilePage(userId) {
	const [profile, interests] = await Promise.all([
		getUserProfile(userId),
		getUserInterests(userId)
	]);

	// 渲染交互统计
	renderStatCard('浏览互动', profile.interactionCount);

	// 渲染偏好分类
	renderCategoryChart(profile.topCategories);
}
```

### 场景三：用户注销时清理

```javascript
async function onUserDeleted(userId) {
	await deleteUser(userId);
}
```
