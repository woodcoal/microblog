# 第四章：推荐与发现

睦谈的推荐完全在本地 TypeScript Service 中完成，不依赖 DaLi.Lens 或外部推荐服务。

热门流固定读取最新 200 条非全局置顶帖子，再做可见度、范围和互动筛选。分数为 `ln(1+点赞) + 2ln(1+收藏) + 3ln(1+独立评论者)`，随后使用 48 小时半衰期衰减。全局置顶不占这 200 条窗口，只在首页和微博热门首页前置。

新用户可保存标签/分类兴趣或明确跳过；系统绝不自动关注，也不持久化推荐结果。有效正向信号达到 5 个且覆盖 3 篇内容或 2 位创作者后，推荐按 50% 兴趣、40% 热门、10% 探索合成；冷启动使用 70% 热门、30% 探索。每个请求即时计算并稳定排序。
