# 第四章：推荐与发现

推荐是 DaLi.Lens 的核心能力。基于用户画像和文档向量相似度，系统为每个用户返回最匹配其兴趣的内容。

---

## 4.1 核心概念

### 推荐原理

DaLi.Lens 使用混合推荐策略：

1. **向量相似度**：计算用户画像向量与文档向量的余弦相似度
2. **关键词匹配**：基于用户偏好的关键词标签匹配文档
3. **质量评分**：结合文档质量分调整排序

最终推荐分数 = `向量权重 × 向量分 + 关键词权重 × 关键词分 + 质量权重 × 质量分`

### 冷启动处理

新用户（无画像数据）不会得到空结果，系统会返回：

- **无分类过滤**：该渠道最近入库的热门文档（按时间倒序）
- **有分类过滤**：该分类下最近入库的文档

随着用户反馈的积累，推荐结果会逐步从"热门推荐"过渡到"个性化推荐"。

---

## 4.2 个性化推荐

获取为指定用户量身定制的推荐列表。

### 接口

```
GET /api/public/recommendations/{userId}?category=云原生&topK=10
```

### 参数

| 参数       | 类型   | 必填 | 说明                                     |
| ---------- | ------ | ---- | ---------------------------------------- |
| `userId`   | string | 是   | 路径参数，你的业务用户 ID，最大 128 字符 |
| `category` | string | 否   | 按分类过滤，不传则返回所有分类           |
| `topK`     | int    | 否   | 返回数量，默认 10，最大 100              |

### 响应

```json
{
	"success": true,
	"data": {
		"userId": "user_12345",
		"items": [
			{
				"documentId": "1893456789012345678",
				"title": "Kubernetes 集群部署指南",
				"summary": "本文介绍 Kubernetes 集群部署的完整流程...",
				"category": "云原生",
				"score": 0.9542
			},
			{
				"documentId": "1893456789012345680",
				"title": "Docker Compose 实战",
				"summary": "从零开始学习 Docker Compose...",
				"category": "云原生",
				"score": 0.8913
			}
		]
	}
}
```

### 字段说明

| 字段         | 说明                               |
| ------------ | ---------------------------------- |
| `documentId` | 文档的系统内部 ID（非 externalId） |
| `title`      | 文档标题                           |
| `summary`    | 文档摘要（AI 生成）                |
| `category`   | 文档分类                           |
| `score`      | 推荐匹配分，0~1 之间，越高越匹配   |

### 前端集成示例

```javascript
/**
 * 获取个性化推荐
 * @param {string} userId - 业务用户 ID
 * @param {Object} [options] - 可选参数
 * @param {string} [options.category] - 分类过滤
 * @param {number} [options.topK=10] - 返回数量
 * @returns {Promise<Array>} 推荐列表
 */
async function getRecommendations(userId, options = {}) {
	const params = new URLSearchParams();
	if (options.category) params.set('category', options.category);
	if (options.topK) params.set('topK', options.topK);

	const result = await callApi(`${BASE_URL}/api/public/recommendations/${userId}?${params}`);
	return result.items;
}
```

### 典型场景：首页推荐流

```javascript
async function renderHomeFeed(userId) {
	const items = await getRecommendations(userId, { topK: 20 });

	const html = items
		.map(
			(item) => `
    <div class="card" data-doc-id="${item.documentId}">
      <h3>${item.title}</h3>
      <p>${item.summary}</p>
      <span class="category">${item.category}</span>
      <span class="score">匹配度 ${Math.round(item.score * 100)}%</span>
    </div>
  `
		)
		.join('');

	document.getElementById('feed').innerHTML = html;
}
```

### 典型场景：分类 Tab 切换

```javascript
async function onCategoryTabClick(userId, category) {
	const items = await getRecommendations(userId, { category, topK: 10 });
	renderCardList(items);
}
```

## 4.3 相似文档推荐

查找与指定文档相似的其他文档，适用于"相关推荐"、"猜你喜欢"等场景。

### 接口

```
GET /api/public/recommendations/{userId}/similar/{externalId}?topK=10
```

### 参数

| 参数         | 类型   | 必填 | 说明                        |
| ------------ | ------ | ---- | --------------------------- |
| `userId`     | string | 是   | 路径参数，用户 ID           |
| `externalId` | string | 是   | 路径参数，外部文档 ID       |
| `topK`       | int    | 否   | 返回数量，默认 10，最大 100 |

### 响应

格式同个性化推荐。

### 前端集成示例

```javascript
/**
 * 获取相似文档
 * @param {string} userId - 业务用户 ID
 * @param {string} externalId - 当前文档的外部 ID
 * @param {number} [topK=10] - 返回数量
 */
async function getSimilarDocuments(userId, externalId, topK = 10) {
	const result = await callApi(
		`${BASE_URL}/api/public/recommendations/${userId}/similar/${externalId}?topK=${topK}`
	);
	return result.items || result;
}
```

### 典型场景：文章详情页的"相关推荐"

```javascript
async function renderRelatedArticles(userId, currentArticleId) {
	const similar = await getSimilarDocuments(userId, currentArticleId, 5);

	const html = similar
		.map(
			(item) => `
    <a href="/articles/${item.documentId}" class="related-card">
      <h4>${item.title}</h4>
      <p>${item.summary}</p>
    </a>
  `
		)
		.join('');

	document.getElementById('related').innerHTML = html;
}
```

## 4.4 种子推荐

根据关键词或内容文本返回相关文档，适用于**新用户首次访问**时没有画像数据的场景。

### 接口

```
POST /api/public/recommendations/seed
```

### 请求体

```json
{
	"keywords": "Kubernetes,Docker,云原生",
	"content": null,
	"category": "云原生",
	"topK": 10
}
```

| 字段       | 类型   | 必填               | 说明                        |
| ---------- | ------ | ------------------ | --------------------------- |
| `keywords` | string | 与 content 二选一  | 关键词列表，逗号分隔        |
| `content`  | string | 与 keywords 二选一 | 内容文本，系统会提取语义    |
| `category` | string | 否                 | 分类过滤                    |
| `topK`     | int    | 否                 | 返回数量，默认 10，最大 100 |

### 前端集成示例

```javascript
/**
 * 种子推荐 — 根据关键词或内容获取推荐
 * @param {Object} params - 推荐参数
 * @param {string} [params.keywords] - 关键词（逗号分隔）
 * @param {string} [params.content] - 内容文本
 * @param {string} [params.category] - 分类过滤
 * @param {number} [params.topK=10] - 返回数量
 */
async function getSeedRecommendations(params) {
	return await callApi(`${BASE_URL}/api/public/recommendations/seed`, {
		method: 'POST',
		body: JSON.stringify(params)
	});
}
```

### 典型场景：新用户兴趣选择

```javascript
// 用户选择感兴趣的标签后，获取初始推荐
async function onInterestTagsSelected(selectedTags) {
	const result = await getSeedRecommendations({
		keywords: selectedTags.join(','),
		topK: 15
	});

	renderInitialFeed(result.items || result);
}
```

### 典型场景：搜索式推荐

```javascript
// 用户输入一段描述，获取语义匹配的文档
async function onSearchQuery(query) {
	const result = await getSeedRecommendations({
		content: query,
		topK: 10
	});

	renderSearchResults(result.items || result);
}
```

## 4.5 推荐策略选择指南

| 场景                 | 推荐接口                   | 说明                           |
| -------------------- | -------------------------- | ------------------------------ |
| 首页信息流           | 个性化推荐                 | 基于用户画像推荐               |
| 分类浏览             | 个性化推荐 + category 参数 | 在特定分类内推荐               |
| 文章详情页"相关推荐" | 相似文档推荐               | 基于当前文档找相似             |
| 新用户首次访问       | 种子推荐                   | 用户选择兴趣标签后获取初始内容 |
| 搜索/发现            | 种子推荐                   | 用 content 参数做语义搜索      |
| 用户画像不成熟时     | 种子推荐                   | 用已知关键词补充推荐           |

## 4.6 性能建议

1. **缓存推荐结果**：推荐接口有内部缓存（默认 TTL 由服务端配置），但前端也应适当缓存，避免短时间内重复请求
2. **分页加载**：首次加载 10 条，滚动到底部时再请求下一批
3. **预加载**：在用户即将看到推荐区域时提前请求
4. **降级处理**：推荐接口 502 时展示热门内容作为兜底

```javascript
// 推荐降级示例
async function loadFeedWithFallback(userId) {
	try {
		return await getRecommendations(userId, { topK: 10 });
	} catch (err) {
		if (err.code?.includes('UNAVAILABLE')) {
			// 服务不可用，展示按时间排序的最新内容
			return await listDocuments({ status: 'completed', pageSize: 10 });
		}
		throw err;
	}
}
```
