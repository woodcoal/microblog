# 第五章：智能问答

DaLi.Lens 提供基于知识库的 RAG（检索增强生成）问答能力。用户提出问题后，系统检索相关文档并由 LLM 生成回答，同时返回引用来源。

---

## 5.1 核心概念

### RAG 问答流程

```
用户提问 → 向量检索相关文档 → 拼接上下文 → LLM 生成回答 → 返回答案 + 引用来源
```

### 前置条件

- 问答依赖已入库且状态为 `completed` 的文档
- 确保文档内容与用户可能提出的问题相关
- LLM 服务需要正常运行（否则返回 502 错误）

---

## 5.2 问答接口

### 接口

```
POST /api/public/qa
```

### 请求体

```json
{
	"query": "如何配置 PVE 网络？"
}
```

| 字段    | 类型   | 必填 | 约束          | 说明     |
| ------- | ------ | ---- | ------------- | -------- |
| `query` | string | 是   | 最大 500 字符 | 用户问题 |

### 成功响应

```json
{
	"success": true,
	"data": {
		"query": "如何配置 PVE 网络？",
		"answer": "要配置 PVE 网络，首先需要创建 Linux Bridge，然后配置 VLAN 和 IP 地址。具体步骤如下：\n1. 在 PVE 管理界面选择「网络」\n2. 点击「创建」→「Linux Bridge」\n3. 配置桥接端口和 IP 地址\n4. 保存并应用配置",
		"sources": [
			{
				"documentId": "1893456789012345678",
				"title": "PVE 网络配置指南",
				"snippet": "PVE 网络配置的基本步骤如下：1. 创建 Linux Bridge..."
			},
			{
				"documentId": "1893456789012345680",
				"title": "PVE 高级网络设置",
				"snippet": "在完成基础网络配置后，可以进一步配置 VLAN..."
			}
		]
	}
}
```

### 字段说明

| 字段                   | 说明              |
| ---------------------- | ----------------- |
| `query`                | 用户原始问题      |
| `answer`               | LLM 生成的回答    |
| `sources`              | 引用来源列表      |
| `sources[].documentId` | 来源文档的系统 ID |
| `sources[].title`      | 来源文档标题      |
| `sources[].snippet`    | 匹配的文档片段    |

### 错误响应

| 场景             | 错误码                  | HTTP 状态码 | 说明                            |
| ---------------- | ----------------------- | ----------- | ------------------------------- |
| 问题为空或超长   | `VALIDATION_ERROR`      | 400         | 前端预校验                      |
| 未找到相关文档   | `NO_RELEVANT_DOCS`      | 200         | 业务层失败，HTTP 状态码仍为 200 |
| LLM 服务不可用   | `LLM_UNAVAILABLE`       | 502         | 稍后重试                        |
| 向量化服务不可用 | `EMBEDDING_UNAVAILABLE` | 502         | 稍后重试                        |

> **注意**：`NO_RELEVANT_DOCS` 的 HTTP 状态码是 200，但 `success` 为 `false`。前端需要检查 `success` 字段而非 HTTP 状态码。

## 5.3 前端集成示例

### 基础问答函数

```javascript
/**
 * 提交问答请求
 * @param {string} query - 用户问题
 * @returns {Promise<Object>} 问答结果
 */
async function askQuestion(query) {
	return await callApi(`${BASE_URL}/api/public/qa`, {
		method: 'POST',
		body: JSON.stringify({ query })
	});
}
```

### 完整问答组件

```javascript
class QaWidget {
	constructor(containerId) {
		this.container = document.getElementById(containerId);
		this.isLoading = false;
		this.render();
	}

	render() {
		this.container.innerHTML = `
      <div class="qa-widget">
        <div class="qa-input-area">
          <input type="text" id="qa-input" placeholder="输入你的问题..." maxlength="500" />
          <button id="qa-submit" onclick="qaWidget.submit()">提问</button>
        </div>
        <div id="qa-result"></div>
      </div>
    `;

		// 回车提交
		document.getElementById('qa-input').addEventListener('keydown', (e) => {
			if (e.key === 'Enter') this.submit();
		});
	}

	async submit() {
		const input = document.getElementById('qa-input');
		const query = input.value.trim();
		if (!query || this.isLoading) return;

		this.isLoading = true;
		this.showLoading();

		try {
			const result = await askQuestion(query);
			this.showResult(result);
		} catch (err) {
			this.showError(err);
		} finally {
			this.isLoading = false;
		}
	}

	showLoading() {
		document.getElementById('qa-result').innerHTML = `
      <div class="qa-loading">正在思考中...</div>
    `;
	}

	showResult(result) {
		const sourcesHtml = result.sources
			.map(
				(s) => `
      <div class="qa-source">
        <span class="source-title">${s.title}</span>
        <p class="source-snippet">${s.snippet}</p>
      </div>
    `
			)
			.join('');

		document.getElementById('qa-result').innerHTML = `
      <div class="qa-answer">
        <div class="answer-text">${result.answer}</div>
        ${
			result.sources.length > 0
				? `
          <div class="qa-sources">
            <h4>参考来源</h4>
            ${sourcesHtml}
          </div>
        `
				: ''
		}
      </div>
    `;
	}

	showError(err) {
		const messages = {
			NO_RELEVANT_DOCS: '未找到与您问题相关的内容，请尝试换个方式提问',
			LLM_UNAVAILABLE: 'AI 服务暂时不可用，请稍后再试',
			EMBEDDING_UNAVAILABLE: '检索服务暂时不可用，请稍后再试'
		};

		document.getElementById('qa-result').innerHTML = `
      <div class="qa-error">${messages[err.code] || '提问失败，请稍后重试'}</div>
    `;
	}
}

// 初始化
const qaWidget = new QaWidget('qa-container');
```

## 5.4 典型场景

### 场景一：帮助中心/知识库搜索

```javascript
// 替代传统关键词搜索，使用语义问答
async function onHelpSearch(query) {
	try {
		const result = await askQuestion(query);
		renderHelpAnswer(result.answer, result.sources);
	} catch (err) {
		if (err.code === 'NO_RELEVANT_DOCS') {
			showTip('未找到相关帮助文档，请联系客服');
		}
	}
}
```

### 场景二：浮动问答助手

```javascript
// 页面右下角的浮动问答按钮
class FloatingQaAssistant {
	constructor() {
		this.isOpen = false;
		this.history = [];
	}

	toggle() {
		this.isOpen = !this.isOpen;
		this.render();
	}

	async ask(query) {
		this.history.push({ role: 'user', content: query });
		this.render();

		try {
			const result = await askQuestion(query);
			this.history.push({
				role: 'assistant',
				content: result.answer,
				sources: result.sources
			});
		} catch (err) {
			this.history.push({ role: 'assistant', content: '抱歉，暂时无法回答', error: true });
		}

		this.render();
	}
}
```

### 场景三：文档内嵌问答

```javascript
// 在文档详情页提供"针对本文提问"功能
async function askAboutDocument(query, documentExternalId) {
	// 使用种子推荐接口验证文档存在性，然后调用 QA
	const result = await askQuestion(`关于"${documentExternalId}"：${query}`);
	return result;
}
```

## 5.5 注意事项

1. **问答延迟**：LLM 生成回答通常需要 2-10 秒，前端应展示加载状态
2. **问题长度**：限制在 500 字符以内，前端应做输入校验
3. **无结果处理**：`NO_RELEVANT_DOCS` 不是错误，应友好提示用户换种方式提问
4. **引用展示**：建议展示引用来源，增加回答的可信度
5. **服务降级**：LLM 不可用时，可降级为关键词搜索（使用文档列表接口）
