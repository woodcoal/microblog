# 第八章：错误处理与最佳实践

本章汇总 DaLi.Lens API 的错误处理策略、重试机制和前端集成最佳实践。

---

## 8.1 错误码完整参考

### 客户端错误（4xx）

| HTTP 状态码 | 错误码                   | 含义               | 前端处理                   |
| ----------- | ------------------------ | ------------------ | -------------------------- |
| 400         | `VALIDATION_ERROR`       | 请求参数校验失败   | 检查请求参数，前端预校验   |
| 401         | `UNAUTHORIZED`           | API Key 无效或缺失 | 检查认证配置，提示重新登录 |
| 403         | `FORBIDDEN`              | 渠道已禁用         | 联系管理员                 |
| 404         | `NOT_FOUND`              | 资源不存在         | 提示用户或跳转             |
| 409         | `CONFLICT` / `DUPLICATE` | 资源重复           | 提示已存在或使用更新接口   |
| 413         | `CONTENT_TOO_LARGE`      | 文档内容超过 50KB  | 前端限制输入长度           |

### 服务端错误（5xx）

| HTTP 状态码 | 错误码                      | 含义             | 前端处理       |
| ----------- | --------------------------- | ---------------- | -------------- |
| 500         | `INTERNAL_ERROR`            | 服务器内部错误   | 稍后重试       |
| 501         | `ALGORITHM_NOT_IMPLEMENTED` | 不支持的算法     | 切换为默认算法 |
| 502         | `EMBEDDING_UNAVAILABLE`     | 向量化服务不可用 | 稍后重试       |
| 502         | `LLM_UNAVAILABLE`           | LLM 服务不可用   | 稍后重试       |
| 502         | `SERVICE_UNAVAILABLE`       | 外部服务不可用   | 稍后重试       |
| 503         | `UNHEALTHY`                 | 服务不健康       | 稍后重试       |

### 业务层失败（HTTP 200 但 success=false）

| 错误码             | 含义           | 前端处理             |
| ------------------ | -------------- | -------------------- |
| `NO_RELEVANT_DOCS` | 未找到相关文档 | 提示用户换种方式提问 |

## 8.2 通用错误处理函数

```javascript
/**
 * 统一 API 调用 — 含错误处理
 * @param {string} url - 请求 URL
 * @param {Object} [options] - fetch 选项
 * @param {Object} [errorConfig] - 错误处理配置
 * @returns {Promise<Object>} 成功时返回 data
 */
async function callApi(url, options = {}, errorConfig = {}) {
	const {
		silent = false, // 是否静默（不弹提示）
		retryOn5xx = false, // 5xx 是否自动重试
		maxRetries = 2, // 最大重试次数
		fallbackData = null // 失败时的兜底数据
	} = errorConfig;

	let lastError;

	for (let attempt = 0; attempt <= (retryOn5xx ? maxRetries : 0); attempt++) {
		try {
			const response = await fetch(url, {
				...options,
				headers: {
					Authorization: `Bearer ${API_KEY}`,
					'Content-Type': 'application/json',
					...options.headers
				}
			});

			const result = await response.json();

			if (result.success) {
				return result.data;
			}

			// 业务层失败
			lastError = {
				code: result.error.code,
				message: result.error.message,
				status: response.status
			};
			break; // 业务层失败不重试
		} catch (err) {
			lastError = { code: 'NETWORK_ERROR', message: '网络请求失败', status: 0 };

			if (retryOn5xx && attempt < maxRetries) {
				await sleep(1000 * (attempt + 1)); // 递增延迟
				continue;
			}
		}
	}

	// 所有重试都失败
	if (!silent) {
		showErrorMessage(lastError);
	}

	if (fallbackData !== null) {
		return fallbackData;
	}

	throw lastError;
}

function sleep(ms) {
	return new Promise((resolve) => setTimeout(resolve, ms));
}
```

## 8.3 重试策略

### 需要重试的场景

| 场景           | 重试策略            | 说明         |
| -------------- | ------------------- | ------------ |
| 网络超时       | 指数退避，最多 3 次 | 1s → 2s → 4s |
| 502 服务不可用 | 固定间隔，最多 2 次 | 间隔 2s      |
| 503 服务不健康 | 固定间隔，最多 2 次 | 间隔 5s      |

### 不需要重试的场景

| 场景           | 原因                            |
| -------------- | ------------------------------- |
| 400 参数错误   | 请求本身有问题，重试不会成功    |
| 401 未认证     | 需要修正认证信息                |
| 404 资源不存在 | 资源确实不存在                  |
| 409 资源冲突   | 业务逻辑冲突，需调整            |
| 业务层失败     | 如 NO_RELEVANT_DOCS，非技术错误 |

### 重试实现

```javascript
/**
 * 带指数退避的重试
 * @param {Function} fn - 异步函数
 * @param {number} [maxRetries=3] - 最大重试次数
 * @param {number} [baseDelay=1000] - 基础延迟（毫秒）
 */
async function retryWithBackoff(fn, maxRetries = 3, baseDelay = 1000) {
	let lastError;

	for (let i = 0; i <= maxRetries; i++) {
		try {
			return await fn();
		} catch (err) {
			lastError = err;

			// 只对 5xx 和网络错误重试
			const shouldRetry = !err.status || err.status >= 500;
			if (!shouldRetry || i === maxRetries) break;

			const delay = baseDelay * Math.pow(2, i);
			await sleep(delay);
		}
	}

	throw lastError;
}

// 使用示例
const recommendations = await retryWithBackoff(
	() => getRecommendations(userId, { topK: 10 }),
	2,
	1000
);
```

## 8.4 降级策略

当 DaLi.Lens 服务不可用时，前端应有合理的降级方案，确保用户体验不受严重影响。

| 功能         | 降级方案                               |
| ------------ | -------------------------------------- |
| 个性化推荐   | 展示按时间排序的最新内容               |
| 相似文档推荐 | 展示同分类下的其他文档                 |
| 智能问答     | 展示"暂不可用"提示，提供关键词搜索替代 |
| 兴趣评分     | 跳过评分，按默认顺序展示               |
| 反馈提交     | 静默失败，本地缓存稍后重试             |
| 用户画像     | 不展示画像信息                         |

```javascript
// 推荐降级示例
async function loadFeedWithFallback(userId) {
	try {
		return await retryWithBackoff(() => getRecommendations(userId, { topK: 10 }), 1);
	} catch (err) {
		console.warn('推荐服务不可用，降级为最新内容');
		return await listDocuments({ status: 'completed', pageSize: 10 });
	}
}

// QA 降级示例
async function askWithFallback(query) {
	try {
		return await askQuestion(query);
	} catch (err) {
		if (err.code?.includes('UNAVAILABLE')) {
			return {
				answer: '智能问答暂时不可用，您可以尝试使用搜索功能查找相关内容。',
				sources: [],
				fallback: true
			};
		}
		throw err;
	}
}
```

## 8.5 前端集成最佳实践

### 1. API Key 安全

```javascript
// 错误：直接在前端代码中硬编码 API Key
const API_KEY = 'dll_a1b2c3d4e5f6...'; // 不要这样做！

// 正确：通过后端代理
async function callApi(path, options = {}) {
	return await fetch(`/api/proxy${path}`, options); // 后端转发，API Key 存储在服务端
}
```

### 2. 请求防抖与节流

```javascript
// 搜索输入防抖
function debounce(fn, delay) {
	let timer;
	return (...args) => {
		clearTimeout(timer);
		timer = setTimeout(() => fn(...args), delay);
	};
}

const debouncedSearch = debounce(async (query) => {
	const results = await getSeedRecommendations({ content: query });
	renderResults(results);
}, 300);
```

### 3. 加载状态管理

```javascript
async function withLoading(asyncFn, loadingElement) {
	loadingElement.classList.add('loading');
	try {
		return await asyncFn();
	} finally {
		loadingElement.classList.remove('loading');
	}
}

// 使用
const data = await withLoading(
	() => getRecommendations(userId),
	document.getElementById('feed-container')
);
```

### 4. 请求取消

```javascript
// 使用 AbortController 取消过时的请求
let currentController = null;

async function searchWithCancel(query) {
	// 取消上一次请求
	if (currentController) {
		currentController.abort();
	}

	currentController = new AbortController();

	try {
		const result = await callApi(`${BASE_URL}/api/public/recommendations/seed`, {
			method: 'POST',
			body: JSON.stringify({ content: query }),
			signal: currentController.signal
		});
		return result;
	} catch (err) {
		if (err.name === 'AbortError') return null; // 请求被取消，静默处理
		throw err;
	}
}
```

### 5. 数据缓存

```javascript
// 简易内存缓存
const cache = new Map();

async function cachedApiCall(key, fn, ttlMs = 5 * 60 * 1000) {
	const cached = cache.get(key);
	if (cached && Date.now() - cached.time < ttlMs) {
		return cached.data;
	}

	const data = await fn();
	cache.set(key, { data, time: Date.now() });
	return data;
}

// 使用：推荐结果缓存 5 分钟
const recommendations = await cachedApiCall(
	`rec:${userId}`,
	() => getRecommendations(userId, { topK: 10 }),
	5 * 60 * 1000
);
```

### 6. 反馈本地队列

```javascript
// 反馈提交失败时存入本地，稍后重试
class FeedbackQueue {
	constructor() {
		this.queue = JSON.parse(localStorage.getItem('feedback_queue') || '[]');
		this.flushing = false;
	}

	async enqueue(userId, documentId, action) {
		this.queue.push({ userId, documentId, action, timestamp: Date.now() });
		this.save();
		this.flush();
	}

	async flush() {
		if (this.flushing || this.queue.length === 0) return;
		this.flushing = true;

		while (this.queue.length > 0) {
			const item = this.queue[0];
			try {
				await submitFeedback(item.userId, item.documentId, item.action);
				this.queue.shift();
				this.save();
			} catch {
				break; // 失败则停止，下次再试
			}
		}

		this.flushing = false;
	}

	save() {
		localStorage.setItem('feedback_queue', JSON.stringify(this.queue));
	}
}

const feedbackQueue = new FeedbackQueue();

// 使用：反馈失败时自动进入本地队列
async function safeFeedback(userId, documentId, action) {
	try {
		await submitFeedback(userId, documentId, action);
	} catch {
		feedbackQueue.enqueue(userId, documentId, action);
	}
}
```

## 8.6 完整集成模板

以下是一个最小可用的前端集成模板：

```javascript
// ==================== 配置 ====================
const BASE_URL = '/api/proxy'; // 通过后端代理转发

// ==================== 基础请求 ====================
async function callApi(url, options = {}) {
	const response = await fetch(`${BASE_URL}${url}`, {
		...options,
		headers: {
			'Content-Type': 'application/json',
			...options.headers
		}
	});

	const result = await response.json();
	if (result.success) return result.data;
	throw { code: result.error.code, message: result.error.message, status: response.status };
}

// ==================== 文档 ====================
async function ingestDocument(doc) {
	return callApi('/api/documents', { method: 'POST', body: JSON.stringify(doc) });
}

async function getDocumentStatus(externalId) {
	return callApi(`/api/documents/${externalId}`);
}

// ==================== 用户 ====================
async function createUser(user) {
	return callApi('/api/users', { method: 'POST', body: JSON.stringify(user) });
}

async function getUserProfile(userId) {
	try {
		return await callApi(`/api/users/${userId}/profile`);
	} catch {
		return { interactionCount: 0, topCategories: [] };
	}
}

// ==================== 推荐 ====================
async function getRecommendations(userId, options = {}) {
	const params = new URLSearchParams();
	if (options.category) params.set('category', options.category);
	if (options.topK) params.set('topK', options.topK);
	const result = await callApi(`/api/public/recommendations/${userId}?${params}`);
	return result.items;
}

async function getSimilarDocs(userId, externalId, topK = 5) {
	const result = await callApi(
		`/api/public/recommendations/${userId}/similar/${externalId}?topK=${topK}`
	);
	return result.items || result;
}

// ==================== 问答 ====================
async function askQuestion(query) {
	return callApi('/api/public/qa', { method: 'POST', body: JSON.stringify({ query }) });
}

// ==================== 反馈 ====================
async function submitFeedback(userId, documentId, action) {
	return callApi(`/api/users/${userId}/feedback`, {
		method: 'POST',
		body: JSON.stringify({ documentId, action })
	});
}

// ==================== 兴趣评分 ====================
async function scoreInterest(userId, content, algorithm = 'vector') {
	return callApi('/api/public/interest-score', {
		method: 'POST',
		body: JSON.stringify({ userId, content, algorithm })
	});
}
```
