## M1-T1：项目初始化与基础架构

### 目标

搭建 Astro 项目骨架，配置 Prisma + SQLite，建立目录结构和基础工具函数，确保开发环境可运行。

### 步骤

1. `npm create astro@latest` 初始化项目，选择 SSR 模式
2. 安装并配置 UnoCSS
3. 安装 Prisma，初始化 `schema.prisma`，先创建 User 模型
4. 执行 `prisma migrate dev` 生成数据库
5. 创建目录结构：`src/pages/api/`、`src/lib/`、`src/components/`
6. 编写 `src/lib/db.ts`：Prisma Client 单例
7. 编写 `src/lib/config.ts`：环境变量和配置常量
8. 编写 `.env.example`：列出所有环境变量
9. 创建基础布局组件 `src/layouts/Base.astro`：HTML 骨架 + 导航栏占位

### 效果

- `npm run dev` 可启动开发服务器
- Prisma 连接 SQLite 成功，数据库文件生成
- 基础布局页面可访问，导航栏显示站点标题
- 项目目录结构清晰，工具函数就位

### 验证

- 访问 `http://localhost:4321/` 看到空白首页（有导航栏）
- `npx prisma studio` 可打开数据库管理界面
- `npm run build` 构建无报错

## M1-T2：用户注册与登录

### 目标

实现用户注册、登录、登出的完整流程，包括 JWT 认证中间件，使系统能识别用户身份。

### 步骤

1. Prisma schema 添加 User 模型完整字段
2. 编写 `src/lib/auth.ts`：
    - `RESERVED_USERNAMES` 常量（login、register、admin、search、api、following、followers、notifications、settings、tags、latest 等）
    - `hashPassword()` / `verifyPassword()`：bcrypt 封装
    - `generateToken()` / `verifyToken()`：JWT 封装
    - `getUserFromRequest()`：从请求中提取并验证用户
3. 实现 API：
    - `POST /api/auth/register`：校验 → 哈希密码 → 创建用户 → 返回 token
    - `POST /api/auth/login`：校验 → 验证密码 → 返回 token
    - `POST /api/auth/logout`：客户端清除 token 即可
4. 创建页面：
    - `src/pages/login.astro`：邮箱 + 密码登录表单
    - `src/pages/register.astro`：注册表单（含用户名、显示名、邮箱、密码）
5. 前端交互用 React Island 组件处理表单提交和 token 存储（localStorage）

### 效果

- 注册页：填写信息后可成功注册，保留词用户名被拦截，密码不足8位被拦截
- 登录页：输入邮箱密码可登录，登录后导航栏显示用户名
- JWT token 存储在 localStorage，后续请求自动携带
- 登出后 token 清除，页面回到未登录状态

### 验证

- 注册一个新用户，检查数据库中用户记录存在且密码已哈希
- 尝试注册保留词用户名（如 admin），返回错误提示
- 登录后刷新页面，仍保持登录状态
- 使用错误密码登录，返回错误提示
- 登出后，访问需要认证的 API 返回 401

## M1-T3：基础发帖功能

### 目标

实现发帖和帖子列表展示，包含短链 ID 生成和 Markdown 渲染，使用户能发布和浏览内容。

### 步骤

1. Prisma schema 添加 Post 模型
2. 编写 `src/lib/shortid.ts`：8位字母数字混合 ID 生成器（排除易混淆字符如 0/O、1/l/I）
3. 编写 `src/lib/markdown.ts`：白名单 Markdown 渲染器（仅支持粗体、斜体、删除线、行内代码、链接、换行）
4. 实现 API：
    - `POST /api/posts`：生成短链 ID → 存储原始 Markdown → 返回帖子数据
    - `GET /api/posts`：分页获取公开帖子列表（按时间倒序）
    - `GET /api/posts/:id`：获取单个帖子详情
5. 创建页面：
    - `src/pages/index.astro`：首页，展示公开帖子列表
    - `src/pages/[username]/index.astro`：用户主页，展示该用户帖子
    - `src/pages/[username]/[postId]/index.astro`：帖子详情页
6. 创建 React Island 组件：
    - `PostEditor.tsx`：发帖表单（文本框 + 可见度选择）
    - `PostList.tsx`：帖子列表（支持无限滚动）
    - `PostCard.tsx`：单条帖子卡片

### 效果

- 首页显示所有公开帖子，按时间倒序
- 用户主页只显示该用户的帖子
- 帖子详情页完整展示内容，Markdown 正确渲染
- 发帖后自动跳转到帖子详情页
- 帖子 URL 格式为 `/username/abc123de`

### 验证

- 登录后发一条帖子，检查首页和用户主页都能看到
- 访问帖子 URL，内容正确渲染（粗体、链接等）
- 未登录用户可查看公开帖子，发帖按钮不可见
- 帖子 ID 为8位无规律字符串

## M1-T4：帖子编辑与删除

### 目标

实现帖子编辑（含版本历史）和软删除，使用户能修改和移除自己的内容，且变更可追溯。

### 步骤

1. Prisma schema 添加 PostRevision 模型
2. 实现 API：
    - `PUT /api/posts/:id`：保存旧版本到 PostRevision → 更新内容 → 标记"已编辑"
    - `DELETE /api/posts/:id`：软删除（`isDeleted = true`）
    - `GET /api/posts/:id/revisions`：获取版本历史列表
3. 创建页面：
    - `src/pages/[username]/[postId]/edit.astro`：编辑页面
    - `src/pages/[username]/[postId]/revisions.astro`：版本历史页面
4. 创建 React Island 组件：
    - `RevisionDiff.tsx`：diff 对比展示组件
5. 帖子详情页显示"已编辑"标记和编辑/删除按钮（仅作者可见）

### 效果

- 编辑帖子后，详情页显示"已编辑"标记和编辑时间
- 版本历史页按时间倒序展示所有版本
- 可选择任意两个版本进行 diff 对比
- 删除帖子后，详情页显示"该内容已删除"
- 非作者无法编辑/删除他人帖子

### 验证

- 编辑一条帖子，检查版本历史中有新记录
- 对比两个版本，diff 正确高亮差异
- 删除帖子后访问 URL，显示"该内容已删除"
- 尝试编辑他人帖子，返回 403

## M1-T5：站点配置与注册控制

### 目标

通过 .env 环境变量配置站点核心参数，实现注册开关功能。

### 步骤

1. 在 `.env.example` 中添加站点配置环境变量（SITE_TITLE、SITE_DESCRIPTION、ALLOW_REGISTRATION 等）
2. 编写 `src/lib/config.ts`：读取环境变量，提供类型安全的配置常量和默认值
3. 注册页逻辑：读取配置，`ALLOW_REGISTRATION=false` 时显示"注册已关闭"
4. 导航栏和首页读取配置中的标题和 Logo
5. 注册 API 中检查 `ALLOW_REGISTRATION`，为 false 时返回 403

### 效果

- 修改 .env 中 SITE_TITLE 后重启服务，前端标题更新
- 关闭注册后，注册页显示"注册已关闭"提示，注册 API 返回 403
- 首页和导航栏使用配置中的标题

### 验证

- 修改 .env 中 SITE_TITLE，重启服务，刷新首页确认更新
- 设置 ALLOW_REGISTRATION=false，重启服务，访问注册页看到提示，尝试注册 API 返回错误
- 重新设置 ALLOW_REGISTRATION=true，重启服务，注册功能恢复
