## M2-T1：文件上传系统

### 目标

实现图片和附件上传，含 MD5 去重和引用计数，使帖子支持多媒体内容。

### 步骤

1. Prisma schema 添加 FileStorage 和 Media 模型
2. 编写 `src/lib/upload.ts`：
    - `calculateMD5()`：计算文件 MD5
    - `saveFile()`：MD5 去重 → 存储文件 → 更新引用计数
    - `deleteFile()`：引用计数减 1 → 归零时删除物理文件
3. 实现 API：
    - `POST /api/upload`：接收文件 → 校验类型和大小 → 去重存储 → 返回路径
4. 配置上传路径（环境变量 `UPLOAD_DIR`，默认 `./uploads`）
5. 配置 Astro 静态文件服务，使上传文件可通过 URL 访问
6. 修改发帖 API：支持关联图片和附件
7. 修改 PostRevision：保存 mediaSnapshot（图片/附件 ID 列表 JSON）

### 效果

- 发帖时可上传最多 9 张图片和多个附件
- 帖子详情页正确展示图片和附件下载链接
- 相同文件只存储一份，引用计数正确
- 删除帖子后，无引用的文件被物理删除
- 附件保留原始文件名用于下载

### 验证

- 上传同一张图片两次，检查 FileStorage 只有一条记录，refCount = 2
- 删除其中一个帖子，检查 refCount 减为 1，物理文件仍存在
- 删除两个帖子，检查物理文件被删除
- 上传超大文件或非法类型，返回错误

## M2-T2：评论系统

### 目标

实现二级评论、评论点赞和评论排序，使帖子具备完整的互动能力。

### 步骤

1. Prisma schema 添加 Comment 模型
2. 实现 API：
    - `GET /api/posts/:id/comments`：获取评论列表（支持排序参数）
    - `POST /api/posts/:id/comments`：发表评论（支持 parentId 二级评论）
    - `DELETE /api/comments/:id`：软删除评论
    - `PUT /api/comments/:id/like`：切换点赞
3. 创建 React Island 组件：
    - `CommentList.tsx`：评论列表（支持正序/倒序切换）
    - `CommentForm.tsx`：评论输入框
    - `CommentItem.tsx`：单条评论（含回复按钮、点赞按钮）
4. 评论排序偏好保存到 UserSettings

### 效果

- 帖子详情页下方显示评论列表
- 可发表评论和回复评论（二级）
- 评论可点赞，点赞数正确显示
- 排序切换后偏好持久化，下次登录保持
- 删除评论后显示"该内容已删除"
- 评论继承帖子可见度

### 验证

- 发表评论，帖子详情页可见
- 回复评论，显示在父评论下方
- 切换倒序，刷新后仍为倒序
- 删除评论，显示"该内容已删除"而非消失

## M2-T3：点赞与关注

    - `LikeButton.tsx`：点赞按钮（含动画和计数）
    - `FollowButton.tsx`：关注/取关按钮
7. 用户主页显示粉丝数、关注数、发帖数

### 效果

- 帖子详情页和卡片上有点赞按钮，点击切换状态
- 用户主页有关注按钮，点击切换状态
- `/following` 页面显示关注用户的帖子
- `/followers` 页面显示粉丝列表
- 粉丝数、关注数实时更新

### 验证

- 再次点击取消点赞
- 关注用户后，`/following` 页面出现该用户的帖子

## M2-T4：@提及与#标签

### 目标

实现内容中的 @提及和 #标签自动解析，增强内容的关联性和可发现性。

### 步骤

1. Prisma schema 添加 Tag、PostTag、Mention 模型
2. 编写 `src/lib/parser.ts`：
    - `parseMentions()`：从内容中提取 @username
    - `parseTags()`：从内容中提取 #tag#
3. 修改发帖 API：
    - 存储前解析 @提及和 #标签
    - 自动创建 Tag 记录（如不存在）
    - 创建 PostTag 和 Mention 关联
4. 修改 Markdown 渲染器：
    - `@username` → 可点击链接到用户主页
    - `#tag#` → 可点击链接到标签聚合页
5. 创建页面：
    - `src/pages/tags/[tag].astro`：标签聚合页
6. 实现 API：
    - `GET /api/tags/:name/posts`：获取标签下的帖子列表

### 效果

- 发帖时输入 `@zhangsan` 自动解析为可点击链接
- 发帖时输入 `#技术#` 自动解析为可点击标签
- 标签聚合页展示使用该标签的所有帖子
- 标签使用次数正确统计

### 验证

- 发帖包含 `@username`，帖子详情页显示为可点击链接
- 点击标签链接，跳转到标签聚合页，展示相关帖子
- 同一标签多次使用，统计次数正确

## M2-T5：可见度控制

### 目标

实现帖子7种可见度控制和密码保护交互，使用户能精确控制内容可见范围。

### 步骤

1. 修改发帖/编辑 API：支持设置 visibility 字段
2. 修改帖子查询逻辑：根据可见度过滤（公开时间线只显示 public，关注时间线显示 followers 可见的等）
3. 实现密码保护交互：
    - 帖子详情页：visibility=password 时显示密码输入框
    - 输入正确密码后，sessionStorage 记录过期时间
    - 过期时间内免重复输入
4. 实现 users 可见度：检查当前用户是否在 allowedUserIds 中
5. 修改发帖表单：添加可见度选择器（含密码输入和用户选择）

### 效果

- 发帖时可选择7种可见度
- public 帖子出现在公开时间线和搜索结果
- 非公开帖子不出现在公开时间线
- 密码保护帖子需输入密码才能查看
- 指定用户帖子仅目标用户可见

### 验证

- 发一条 public 帖子，首页可见
- 发一条 followers 帖子，首页不可见，关注者主页可见
- 发一条 password 帖子，输入密码后可查看，10分钟内免重复输入
- 发一条 private 帖子，仅自己可见

## M2-T6：搜索功能

### 目标

实现全局搜索（分区）和用户主页帖子搜索，使用户能快速找到内容和用户。

### 步骤

1. 实现 API：
    - `GET /api/search/posts`：按内容关键词搜索帖子（LIKE 查询）
    - `GET /api/search/users`：按用户名/显示名搜索用户
    - `GET /api/users/:username/posts`：获取用户帖子列表（支持 q 参数搜索）
2. 创建页面：
    - `src/pages/search.astro`：搜索页（分区：用户搜索 + 微博搜索）
3. 修改用户主页：添加搜索框，支持按关键词过滤帖子
4. 创建 React Island 组件：
    - `SearchBox.tsx`：搜索输入框
    - `SearchResults.tsx`：搜索结果展示

### 效果

- 搜索页分为"用户"和"微博"两个标签页
- 输入关键词可搜索用户和帖子
- 用户主页有搜索框，可搜索该用户的帖子
- 搜索结果分页展示

### 验证

- 搜索用户名，结果正确
- 搜索帖子内容，结果正确
- 在用户主页搜索，只显示该用户的匹配帖子
- 搜索无结果时显示空状态
