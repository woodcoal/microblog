# M5 前端重构 — CSS 样式分离 + UI/UX 改进

> 里程碑代号：M5
> 核心目标：重构前端 CSS 架构，分离样式文件，统一设计语言，改进 UI/UX
> 前置依赖：M1-M4 全部完成（系统功能完整）
> 执行时间：2026-06

---

## 背景与动机

原有 CSS 架构的三大问题：

1. **样式全在布局组件里** — Base.astro 的 `<style is:global>` 包含 470+ 行 CSS，Admin.astro 包含 550+ 行 CSS，难以维护和复用
2. **非标准 CSS 变量** — 多处使用 `--color-bg-secondary`、`--text-secondary`、`--border-color` 等未在主题中定义的变量，依赖硬编码回退值
3. **管理后台无主题变量** — Admin.astro 不引用 Base.astro 的主题 CSS 变量，暗色/护眼主题在管理后台完全不可用

## 样式分层架构

```
tokens.css        — 设计令牌 + 主题变量（全局，所有布局导入）
  └── base.css    — 基础样式（全局，Base.astro 导入）
       ├── components.css  — 组件样式（全局，Base.astro + Admin.astro 导入）
       └── admin.css       — 管理后台（仅 Admin.astro 导入）
```

## 关键架构决策

| 决策               | 选项                            | 选择          | 理由                                       |
| ------------------ | ------------------------------- | ------------- | ------------------------------------------ |
| 主题变量位置       | Base.astro / 独立 CSS           | `tokens.css`  | Admin.astro 也需访问，独立文件使两布局共享 |
| CSS 导入方式       | `<link>` / Astro `import`       | `import`      | Astro 构建时会正确打包，生产部署可靠       |
| 移动端导航         | 纯 CSS checkbox / JS 切换       | JS toggle     | 简单直接，无依赖                           |
| Toast 通知         | 框架组件 / 纯 CSS               | 纯 CSS        | 0 JS 依赖，通过 class 切换显示             |
| 颜色混合方案       | Sass / CSS `color-mix`          | `color-mix()` | 现代 CSS，无需预处理器                     |
| 管理后台样式作用域 | `<style is:global>` / `<style>` | `<style>`     | settings 页改用普通 `<style>` 避免全局冲突 |
