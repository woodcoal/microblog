# M7 知音 — Gorse 推荐引擎集成

> 里程碑代号：M7
> 核心目标：集成 Gorse 推荐引擎，实现用户兴趣行为追踪与个性化推荐
> 前置依赖：M1-M6 全部完成
> 执行时间：2026-06

---

## 背景与动机

睦谈 M1-M6 已完成完整的微博/论坛/博客功能闭环，用户可以发帖、评论、点赞、收藏、关注。但内容发现仍依赖时间线排序和热门算法，缺乏个性化推荐能力。

通过集成 [Gorse](https://gorse.io/) 开源推荐引擎，实现：

- **个性化推荐**：根据用户行为（点赞、收藏、评论）推荐感兴趣的帖子
- **相似内容发现**：在帖子详情页推荐相似帖子
- **浏览去重**：已看过的帖子不再推荐
- **冷启动支持**：新用户基于热门/最新内容推荐

Gorse 作为独立服务部署，睦谈通过 REST API 与之交互，松耦合设计确保 Gorse 不可用时不影响主站功能。

## 核心设计决策

### 决策 1：环境变量控制全局启用

`GORSE_ENDPOINT` 未设置时，所有 Gorse 相关功能静默停用，不抛异常、不影响主流程。

**理由**：推荐是增强功能，非核心路径；开发环境和未部署 Gorse 的实例不应受影响。

### 决策 2：异步非阻塞写入

所有 Gorse 写操作（插入反馈、同步帖子）均为异步且不阻塞主流程，失败仅 `console.error`，不冒泡异常。

**理由**：与现有 `logActivity()` 模式一致，推荐数据同步不应影响用户操作响应速度。

### 决策 3：反馈类型与权重映射

| 行为 | Gorse FeedbackType | Value | 说明               |
| ---- | ------------------ | ----- | ------------------ |
| 点赞 | `like`             | 1.0   | 正反馈             |
| 评论 | `comment`          | 1.5   | 正反馈（比点赞强） |
| 收藏 | `bookmark`         | 2.0   | 正反馈（最强信号） |
| 浏览 | `read`             | 0     | 仅去重，不参与训练 |

**理由**：收藏 > 评论 > 点赞，反映用户兴趣程度递减。浏览 Value=0 仅标记已读，Gorse 用 `read_feedback_types` 排除已读内容。

### 决策 4：帖子特征映射

| 睦谈概念                      | Gorse 概念              | 映射方式                      |
| ----------------------------- | ----------------------- | ----------------------------- |
| `Post.id`                     | `ItemId`                | 直接使用 8 位短链 ID          |
| `Post.category.slug`          | `Categories`            | 分类 slug 作为类别            |
| `Post.tags[].name`            | `Categories` + `Labels` | 标签同时作为类别和特征        |
| `Post.mode`                   | `Labels`                | 模式作为内容特征              |
| `Post.title` / `Post.content` | `Comment`               | 标题或内容前 100 字符作为备注 |

**理由**：Gorse 的 Categories 用于分类推荐（按类别过滤），Labels 用于内容特征匹配。标签同时出现在两者中，既支持按标签过滤，也支持基于标签的相似度计算。

### 决策 5：使用 gorsejs SDK

使用官方 TypeScript SDK `gorsejs` 调用 Gorse API，而非手写 fetch。

**理由**：类型安全，API 变更时编译期发现；SDK 封装了分页、错误处理等细节。

### 决策 6：推荐结果经过可见度过滤

从 Gorse 获取推荐 ID 后，查询数据库时应用完整的可见度过滤（7 级可见度系统），确保用户只能看到有权限的内容。

**理由**：Gorse 不了解睦谈的可见度规则，可能推荐用户无权查看的帖子。

## 架构设计

### 模块结构

```
src/lib/gorse.ts                    — Gorse 客户端封装（单例、优雅降级）
src/pages/api/recommend/index.ts    — 个性化推荐 API
src/pages/api/recommend/similar/[id].ts — 相似帖子 API
src/pages/api/recommend/read.ts     — 浏览追踪 API
```

### 数据流

```
用户行为（点赞/收藏/评论/浏览）
  → Astro Actions（toggleLike/toggleBookmark/createComment/...）
  → 异步调用 gorse.insertFeedback() / gorse.deleteFeedback()
  → Gorse 引擎训练模型

帖子创建/更新/删除
  → Astro Actions（createPost/updatePost/deletePost）
  → 异步调用 gorse.upsertItem() / gorse.hideItem()
  → Gorse 引擎更新物品索引

推荐查询
  → 前端 fetch('/api/recommend')
  → gorse.getRecommendations() → 数据库查询 → 可见度过滤 → 返回
```

### 优雅降级策略

| 场景                    | 行为                                              |
| ----------------------- | ------------------------------------------------- |
| `GORSE_ENDPOINT` 未设置 | 所有 Gorse 方法立即返回，不发送请求               |
| Gorse 服务不可用        | 写操作静默失败（console.error），读操作返回空数组 |
| 推荐结果为空            | 首页"猜你喜欢"区域不显示                          |
| 用户未登录              | 不加载推荐区域，不发送浏览追踪                    |

## API 路由

### GET /api/recommend

获取个性化推荐帖子列表。

- **认证**：必须登录
- **参数**：`n`（数量，默认 10，最大 50）、`category`（可选，按分类过滤）
- **响应**：`{ success: true, data: { items: PostCard[] } }`
- **Gorse 未启用**：返回空列表

### GET /api/recommend/similar/[id]

获取与指定帖子相似的帖子列表。

- **认证**：不需要
- **参数**：`n`（数量，默认 5，最大 20）
- **响应**：`{ success: true, data: { items: PostCard[] } }`
- **Gorse 未启用**：返回空列表

### POST /api/recommend/read

记录用户浏览行为。

- **认证**：必须登录
- **请求体**：`{ postId: string }`
- **响应**：`{ success: true, data: { recorded: boolean } }`
- **Gorse 未启用**：返回 `{ recorded: false }`

## Actions 埋点

| Action                       | Gorse 操作                                        | 说明                      |
| ---------------------------- | ------------------------------------------------- | ------------------------- |
| `toggleLike`（点赞）         | `insertFeedback(userId, postId, 'like', ...)`     | 插入点赞反馈              |
| `toggleLike`（取消点赞）     | `deleteFeedback(userId, postId, 'like')`          | 删除点赞反馈              |
| `toggleBookmark`（收藏）     | `insertFeedback(userId, postId, 'bookmark', ...)` | 插入收藏反馈              |
| `toggleBookmark`（取消收藏） | `deleteFeedback(userId, postId, 'bookmark')`      | 删除收藏反馈              |
| `createComment`              | `insertFeedback(userId, postId, 'comment', ...)`  | 插入评论反馈              |
| `createPost`                 | `upsertItem(postId, { categories, labels, ... })` | 同步帖子到 Gorse          |
| `updatePost`                 | `upsertItem(postId, { categories, labels, ... })` | 更新帖子信息              |
| `deletePost`                 | `hideItem(postId)`                                | 隐藏帖子（IsHidden=true） |

## Gorse 服务端配置建议

```toml
# gorse.toml — 睦谈推荐引擎配置

# ===== 数据库（必填） =====
[database]
data_store = "mysql://gorse:password@tcp(localhost:3306)/gorse"
cache_store = "redis://localhost:6379/0"

# ===== 主节点 =====
[master]
http_port = 8088    # Dashboard 和管理 API 端口
n_jobs = 4          # 工作线程数

# ===== 服务器节点（RESTful API） =====
[server]
api_key = "your_api_key"       # RESTful API 密钥，对应睦谈的 GORSE_API_KEY
auto_insert_user = true        # 插入反馈时自动创建用户
auto_insert_item = true        # 插入反馈时自动创建物品
default_n = 10                 # 默认返回数量

# ===== 推荐数据源 =====
[recommend.data_source]
# 正反馈类型（用于训练推荐模型）
positive_feedback_types = ["like", "bookmark", "comment"]
# 读反馈类型（用于去重，不再推荐已读内容）
read_feedback_types = ["read"]
# 正反馈有效期（天），0=不过期
positive_feedback_ttl = 0
# 物品有效期（天），0=不过期
item_ttl = 0

# ===== 协同过滤 =====
[recommend.collaborative]
# 启用协同过滤：type 必须为 "mf"（矩阵分解），默认 "none" 表示禁用
type = "mf"
fit_period = "60m"             # 模型训练周期
fit_epoch = 100                # 每次训练轮数
optimize_period = "360m"       # 超参数搜索周期
optimize_trials = 10           # 超参数搜索试验次数

# ===== 排序器 =====
[recommend.ranker]
type = "fm"                    # 因子分解机排序
fit_period = "60m"
fit_epoch = 100

# ===== 非个性化推荐（冷启动兜底） =====
[[recommend.non-personalized]]
name = "latest"
score = "item.Timestamp.Unix()"

[[recommend.non-personalized]]
name = "most_liked_weekly"
score = "count(feedback, .FeedbackType == 'like')"
filter = "(now() - item.Timestamp).Hours() < 168"

# ===== 物品相似度推荐 =====
# type = "embedding" 表示基于 Labels 中的 embedding 向量计算相似度
# type = "items" 表示基于共同反馈的用户计算相似度
# column 指定使用 Labels 中的哪个字段
[[recommend.item-to-item]]
name = "neighbors"
type = "items"

# ===== 用户相似度推荐 =====
[[recommend.user-to-user]]
name = "neighbors"
type = "items"

# ===== 回退推荐 =====
[recommend.fallback]
recommenders = ["latest"]      # 个性化推荐不足时回退到最新帖子
```

> **重要说明**：
>
> - **gorse-in-one**（单节点模式）的 RESTful API 端口是 **8088**，Dashboard 也在 8088
> - **gorse cluster**（集群模式）的 Server 节点 RESTful API 端口是 **8087**，Master Dashboard 在 8088
> - 睦谈的 `GORSE_ENDPOINT` 应指向 RESTful API 地址：单节点用 `http://127.0.0.1:8088`，集群用 `http://127.0.0.1:8087`
> - `api_key` 在 `[server]` 节下配置，通过 `X-API-Key` header 传递
> - `[[recommend.item-to-item]]` 是双括号（数组格式），可配置多个
> - 协同过滤通过 `type = "mf"` 启用，不是 `enable = true`
> - 验证数据是否入库：访问 Dashboard（`http://localhost:8088`）或调用 `GET /api/feedback?n=10` 查看反馈

## 技术风险与应对

| 风险                        | 影响         | 应对                                                |
| --------------------------- | ------------ | --------------------------------------------------- |
| Gorse 服务不可用            | 推荐功能失效 | 优雅降级，所有操作静默失败，不影响主站              |
| 推荐结果包含无权帖子        | 信息泄露     | API 层完整可见度过滤，逐条验证                      |
| gorsejs SDK API 变更        | 编译错误     | 锁定版本，升级前测试                                |
| 冷启动问题（新用户/新帖子） | 推荐为空     | Gorse 配置非个性化推荐（latest/most_liked）作为兜底 |
| 反馈数据量不足              | 推荐质量差   | 初期可降低推荐区域展示优先级，数据积累后提升        |
| 浏览追踪请求量大            | Gorse 压力大 | 浏览反馈 Value=0，Gorse 可配置批量写入              |
