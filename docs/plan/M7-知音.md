# M7 知音 — DaLi.Lens 推荐中间件集成

> **已归档（2026-08）**：本方案原基于 DaLi.Lens；项目现已切换为本地热门排序与标签/分类匹配，不再依赖该外部服务。以下内容仅保留为历史设计记录。

> 里程碑代号：M7
> 核心目标：集成 DaLi.Lens 推荐中间件，实现用户兴趣行为追踪与个性化推荐
> 前置依赖：M1-M6 全部完成
> 执行时间：2026-06

## 背景与动机

睦谈 M1-M6 已完成完整的微博/论坛/博客功能闭环，用户可以发帖、评论、点赞、收藏、关注。但内容发现仍依赖时间线排序和热门算法，缺乏个性化推荐能力。

通过集成 [DaLi.Lens](https://lens.woodcoal.cn) 推荐中间件，实现：

- **个性化推荐**：根据用户行为（点赞、收藏、评论）推荐感兴趣的帖子
- **相似内容发现**：在帖子详情页推荐相似帖子
- **用户画像**：构建用户兴趣标签画像
- **冷启动支持**：新用户基于热门/最新内容推荐

DaLi.Lens 作为独立服务部署，睦谈通过 REST API 与之交互，松耦合设计确保 Lens 不可用时不影响主站功能。

## 核心设计决策

### 决策 1：环境变量控制全局启用

`LENS_ENDPOINT` 未设置时，所有 Lens 相关功能静默停用，不抛异常、不影响主流程。

**理由**：推荐是增强功能，非核心路径；开发环境和未部署 Lens 的实例不应受影响。

### 决策 2：异步非阻塞写入

所有 Lens 写操作（提交反馈、同步文档）均为异步且不阻塞主流程，失败仅 `console.error`，不冒泡异常。

**理由**：与现有 `logActivity()` 模式一致，推荐数据同步不应影响用户操作响应速度。

### 决策 3：反馈类型映射

| 行为 | Lens FeedbackType | 说明                 |
| ---- | ----------------- | -------------------- |
| 点赞 | `click`           | 点击行为反馈         |
| 评论 | `comment`         | 评论反馈             |
| 收藏 | `fav`             | 收藏反馈（最强信号） |
| 浏览 | `view`            | 浏览行为反馈         |

**理由**：Lens 渠道配置了 fav/click/view/comment 四种反馈类型，与睦谈行为一一对应。取消点赞/取消收藏不发送负向反馈（Lens 无 dislike 类型）。

### 决策 4：文档特征映射

| 睦谈概念                      | Lens 概念           | 映射方式             |
| ----------------------------- | ------------------- | -------------------- |
| `Post.id`                     | `externalId`        | 直接使用 8 位短链 ID |
| `Post.category.name`          | `category`          | 分类名称作为类别     |
| `Post.title` / `Post.content` | `title` / `content` | 标题和内容直接映射   |

**理由**：Lens 的 externalId 用于关联业务系统文档，category 用于分类推荐，title/content 用于语义匹配。

### 决策 5：使用原生 fetch 调用

使用原生 fetch 调用 Lens REST API，封装统一的 `callLens` 函数处理认证和错误。

**理由**：Lens API 为标准 RESTful 接口，无需额外 SDK 依赖；统一封装确保认证和错误处理一致。

### 决策 6：推荐结果经过可见度过滤

从 Lens 获取推荐 ID 后，查询数据库时应用完整的可见度过滤（7 级可见度系统），确保用户只能看到有权限的内容。

**理由**：Lens 不了解睦谈的可见度规则，可能推荐用户无权查看的帖子。

### 决策 7：用户注册时同步到 Lens

用户注册成功后，异步调用 `createUser` 将用户信息同步到 Lens，为构建用户画像提供基础数据。

**理由**：Lens 需要用户信息来构建画像和提供个性化推荐，注册时同步可确保用户数据完整。

## 架构设计

### 模块结构

```
src/lib/lens.ts                     — DaLi.Lens 客户端封装（单例、优雅降级）
src/services/recommend.service.ts   — 推荐业务 Service 层
src/actions/recommend.ts            — 推荐 Actions（getRecommend/getSimilarPosts/recordRead/getUserProfile）
```

### 数据流

```
用户行为（点赞/收藏/评论/浏览）
  → Astro Actions（toggleLike/toggleBookmark/createComment/...）
  → 异步调用 submitFeedback(userId, postId, action)
  → Lens 引擎训练模型

帖子创建/更新/删除
  → Astro Actions（createPost/updatePost/deletePost）
  → 异步调用 ingestDocument / updateDocument / deleteDocument
  → Lens 引擎更新文档索引

用户注册
  → Astro Actions（register）
  → 异步调用 createUser({ userId, username })
  → Lens 构建用户画像基础

推荐查询
  → Astro Actions（getRecommend / getSimilarPosts）
  → Lens API → 数据库查询 → 可见度过滤 → 返回
```

### 优雅降级策略

| 场景                   | 行为                                              |
| ---------------------- | ------------------------------------------------- |
| `LENS_ENDPOINT` 未设置 | 所有 Lens 方法立即返回，不发送请求                |
| Lens 服务不可用        | 写操作静默失败（console.error），读操作返回空数组 |
| 推荐结果为空           | 首页"猜你喜欢"区域不显示                          |
| 用户未登录             | 不加载推荐区域，不发送浏览追踪                    |

## Actions 接口

### getRecommend

获取个性化推荐帖子列表。

- **认证**：必须登录
- **输入**：`{ n?: number }`（数量，默认 10）
- **输出**：`{ items: RecommendItem[] }`
- **Lens 未启用**：返回空列表

### getSimilarPosts

获取与指定帖子相似的帖子列表。

- **认证**：必须登录
- **输入**：`{ postId: string, n?: number }`（数量，默认 5）
- **输出**：`{ items: RecommendItem[] }`
- **Lens 未启用**：返回空列表

### recordRead

记录用户浏览行为。

- **认证**：必须登录
- **输入**：`{ postId: string }`
- **输出**：`{ recorded: boolean }`
- **Lens 未启用**：返回 `{ recorded: false }`

### getUserProfile

获取用户画像。

- **认证**：必须登录
- **输入**：无
- **输出**：用户画像数据
- **Lens 未启用**：返回 null

## Actions 埋点

| Action                       | Lens 操作                                                          | 说明                  |
| ---------------------------- | ------------------------------------------------------------------ | --------------------- |
| `toggleLike`（点赞）         | `submitFeedback(userId, postId, 'click')`                          | 提交点击反馈          |
| `toggleLike`（取消点赞）     | 不发送负向反馈                                                     | Lens 无 dislike 类型  |
| `toggleBookmark`（收藏）     | `submitFeedback(userId, postId, 'fav')`                            | 提交收藏反馈          |
| `toggleBookmark`（取消收藏） | 不发送负向反馈                                                     | Lens 无 dislike 类型  |
| `createComment`              | `submitFeedback(userId, postId, 'comment')`                        | 提交评论反馈          |
| `createPost`                 | `ingestDocument({ externalId, title, content, category })`         | 同步帖子到 Lens       |
| `updatePost`                 | `updateDocument(postId, { externalId, title, content, category })` | 更新帖子信息          |
| `deletePost`                 | `deleteDocument(postId)`                                           | 从 Lens 删除文档      |
| `register`                   | `createUser({ userId, username })`                                 | 注册时同步用户到 Lens |

## 技术风险与应对

| 风险                        | 影响         | 应对                                         |
| --------------------------- | ------------ | -------------------------------------------- |
| Lens 服务不可用             | 推荐功能失效 | 优雅降级，所有操作静默失败，不影响主站       |
| 推荐结果包含无权帖子        | 信息泄露     | Service 层完整可见度过滤，逐条验证           |
| 冷启动问题（新用户/新帖子） | 推荐为空     | Lens 内置热门/最新兜底策略                   |
| 反馈数据量不足              | 推荐质量差   | 初期可降低推荐区域展示优先级，数据积累后提升 |
