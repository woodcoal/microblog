## 结论

M1 里程碑全部 27 项验证通过，功能完整可用。发现并修复了 2 个问题：

1. **登出重定向**：logout API 返回 JSON 改为重定向
2. **.env 变量读取**：Astro/Vite 中 `process.env` 无法读取 .env 文件变量，改用 `import.meta.env`（带 `process.env` 回退）

调整后复验项（验证项 2b、23-25）全部通过，无遗留缺陷。
