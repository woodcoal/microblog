## Bug 记录

### Bug #1：评论点赞 API 返回 404

- **验证项**：#18 评论点赞
- **现象**：点击评论点赞按钮后，API 返回 404，点赞状态未变化
- **API 端点**：`PUT /api/comments/:id/like`
- **根因分析**：评论列表刷新后，DOM 中的评论 ID 可能指向了一个已软删除的评论（来自之前测试运行），导致 `prisma.comment.findUnique({ where: { id } })` 返回 null，API 返回 404
- **影响范围**：评论点赞功能在评论被软删除后不可用
- **建议修复**：
    1. 评论列表 API 应过滤 `isDeleted: true` 的评论
    2. 前端应在评论被删除后移除点赞按钮或禁用

### Bug #2：标签聚合页 PrismaClientValidationError

- **验证项**：#24 标签聚合页
- **现象**：访问 `/tags/提及测试` 页面返回 PrismaClientValidationError
- **错误页面**：`http://localhost:4321/tags/%E6%8F%90%E5%8F%8A%E6%B5%8B%E8%AF%95`
- **根因分析**：`src/pages/tags/[tag].astro` 第 43 行的 `orderBy: [{ post: { createdAt: 'desc' } }]` 语法可能与当前 Prisma 版本不兼容，导致查询验证失败
- **影响范围**：所有标签聚合页无法正常访问
- **建议修复**：
    1. 检查 Prisma 版本是否支持嵌套 relation orderBy
    2. 如不支持，改用先查 PostTag 再手动排序的方式
    3. 或升级 Prisma 到支持该语法的版本
