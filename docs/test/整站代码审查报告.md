## 七、仍需关注的事项

以下问题因需要架构级变更或外部依赖，未在本次修复中处理：

| 事项           | 说明                                                                             |
| -------------- | -------------------------------------------------------------------------------- |
| 速率限制       | 登录/注册/密码验证接口需要添加速率限制中间件，建议使用 `astro-rate-limit` 或自建 |
| CSRF 防护      | 当前依赖 `sameSite: lax` cookie，建议添加 CSRF token 机制                        |
| 管理员操作日志 | 管理员删除帖子/评论未调用 `logActivity`，建议补充                                |
| 评论分页       | 帖子评论列表无分页，大量评论时可能性能问题                                       |
| Webhook 可靠性 | serverless 环境下 fire-and-forget 可能丢失，建议使用消息队列                     |
