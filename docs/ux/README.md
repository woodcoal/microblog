## 睦谈核心页面 UX 原型

本目录提供可直接在浏览器打开的 HTML 原型；均复用项目现有的 4 套主题、间距、圆角与导航基线，并带有主题选择、头像菜单、悬停/焦点状态和小范围交互反馈。

| 页面 | 原型 | 主要 UX 表面 | 核心决策 |
| --- | --- | --- | --- |
| 首页 | `index.html` | 探索 | 跨频道聚合，只承担发现与继续阅读，不重复频道流。 |
| 微博 | `weibo.html` | 探索 | 三栏信息流：稳定导航、主阅读区、轻量发现侧栏；顶部展开式发布。 |
| 论坛 | `forum.html` | 探索 | 以版块和活跃主题组织，帮助用户从“看内容”转为“加入一个持续讨论”。 |
| 博客 | `blog.html` | 决定 / 学习 | 以阅读节奏、摘要和作者脉络为主，避免卡片化淹没长内容。 |
| 用户中心 | `user-center.html` | 配置 | 按任务分区，表单中说明影响范围并使保存动作明确。 |
| 个人主页 | `profile.html` | 探索 | 资料头建立身份，帖子 / 回复 / 喜欢的二级导航支持回看。 |
| 管理后台 | `admin.html` | 监控 / 操作 | 先呈现待处理队列和异常状态，再给运营趋势；避免无意义的大数字。 |

### 详情与列表模板

| 模板 | 原型 | 重点 |
| --- | --- | --- |
| 微博详情 | `weibo-detail.html` | 动态全文、互动操作、回复输入与评论流。 |
| 论坛主题详情 | `forum-detail.html` | 主题上下文、订阅操作和可追溯的讨论回复。 |
| 博客文章详情 | `blog-detail.html` | 长阅读排版、目录、作者信息与文章回应。 |
| 后台帖子列表 | `admin-posts.html` | 搜索筛选、内容状态、行操作和分页。 |

### 设计方向

1. **克制、内容优先（采用）**：严格沿用项目主题令牌：亮色、暗色、护眼与高对比度；主题和强调色都通过 CSS 变量覆盖，不另造独立配色。
2. **频道差异化**：微博追求流式浏览，论坛强调可追溯的话题结构，博客保证长阅读节奏，后台面向处理决策。
3. **统一断点**：所有前台页面使用 960px 内容容器，并统一为桌面（≥1024px）、平板（768–1023px）和移动端（<768px）。后台也在同一容器内居中；平板收拢侧栏，移动端统一为单列。

### 查看方式

直接打开任一 `.html` 文件即可。页面右上角 `◐` 可选择 4 套项目主题及强调色并记住设置；头像会展开“我的主页 / 用户中心 / 通知”等菜单。原型不连接真实业务 API，也不修改生产业务代码。

### 自检

- Slop 诊断：**0/10**。未使用科技渐变、无意义统计牌、居中英雄堆叠或同质化三卡格；各页面的布局与任务表面相匹配。
- 已考虑：键盘可见焦点、移动端 44px 触控目标、四主题对比度、统一断点与减少动态偏好。
